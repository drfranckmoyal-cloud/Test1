# Banque d'images

Dépose ici tout ce que tu trouves, en vrac. **Aucune contrainte** : n'importe
quel nom de fichier, n'importe quelle taille, n'importe quel format courant
(jpg, png, webp). Plusieurs images par personnage, tant mieux — j'aurai le choix.

La seule chose qui m'aide : **mets le nom du personnage dans le nom du fichier**
(`saitama-01.jpg`, `rock-lee-course.png`…). Sinon je trierai à l'œil, ça marche
aussi.

Ce que j'en fais : je sélectionne la meilleure de chaque personnage, je la
recadre au format de l'app, je l'accorde à la palette du programme et je la
place dans le dossier parent sous son nom définitif. Les originaux restent ici,
intacts, pour pouvoir changer d'avis.

Pour les envoyer : dépose les fichiers dans ce dossier, puis

```
git add design-v2/images/banque
git commit -m "Ajoute des illustrations"
git push
```
